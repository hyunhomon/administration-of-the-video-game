# Hackathon demo script (5–8 minutes)

1. Open two browser windows; join same room; move both avatars while party explores.
2. Show independent party profiles and current goal: go to cave.
3. Player 1 approaches thief and claims storehouse has special treasure. Observe skepticism/interest.
4. Player 2 approaches mage and shares a plausible clue that storehouse records explain the seal.
5. Party discusses in short public dialogue; UI surfaces a **decision summary** and updated goal.
6. Party moves toward storehouse (server pathfinding) and inspects; either confirms a clue or discovers deception.
7. Agent trust updates; show subsequent interaction where it remembers the prior human NPC.
8. If live API temporarily unavailable, run clearly labeled deterministic fallback—not a fake live AI result.

## What the judges should see
The exact human utterance, individual agent responses, a valid goal change, and visible world action. Show latency and tool/action event log. Prefer one powerful working causal chain over multiple unrelated AI features.
